Pinned projects:


### Emergent-Communication and geometry of meaning
Ongoing research project on symbol stability, channel discreteness, and meaning formation in agent communication and multilingual embedding space.

I run experiments on discrete vs continuous communication, zero-knowledge style communication metrics, opacity and symbol quality, and translation gaps across languages. The project also explores centroid-based interlingua representations and dense vector communication between AI agents.

### Behavioural-to-Video & Ephys Temporal Alignment
Internship project at the Champalimaud Learning Lab focused on multimodal temporal alignment for neuroscience data.

I developed pipelines to correct clock drift between behavioural state-machine logs, high-speed video, and Neuropixels electrophysiology by detecting anchor events and fitting a robust linear warp. The work combines computer vision, signal processing, and large-scale experimental data analysis.

### Ml-Music-Genre-Classification- Mathematics for Machine Learning course project.
I compared:
- PCA and Kernel PCA
- Eight information-theoretic feature selection methods
- Random Forest and kNN classifiers

I evaluated the methods using Accuracy, Macro Recall, Macro Precision, and Macro F1, and also included a causal analysis component with DAG discovery, do-calculus-inspired interventional predictions, and an interventional robustness score.
